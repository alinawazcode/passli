# Social Content Skill

## Objective
Generate compelling, authentic, and technically grounded LinkedIn, X (Twitter), and blog release notes that resonate with software engineers, security researchers, and tech founders.

## Guidelines
- Start with a strong, relatable hook (a real problem or architectural realization).
- Detail technical mechanics (e.g., cryptographic primitives, Django models, UX friction points).
- Call attention to visual demos or attached video walkthroughs.
- Invite constructive feedback and contributions.
