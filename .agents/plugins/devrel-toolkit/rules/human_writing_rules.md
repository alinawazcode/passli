# Human-Crafted Technical Writing & Social Content Rules

1. **Zero Corporate AI Jargon**:
   - Strictly prohibit tropes like *"I'm thrilled to announce"*, *"In today's fast-paced digital world"*, *"game-changer"*, *"delve into"*, *"testament to"*, or *"revolutionizing"*.
2. **First-Principles Storytelling**:
   - Ground posts in tangible engineering challenges: specific vulnerability vectors, cryptographic decisions, architectural tradeoffs, and authentic developer motivations.
3. **Engaging Formatting & Clear CTA**:
   - Use crisp line spacing, impactful bullet points, code or technical snippets where relevant, and clear links to the GitHub repository and live deployment.
